# BottomSheetManager & ScrollbarManager

A lightweight, zero-dependency Vanilla JavaScript library for creating customizable bottom sheets and managing scrollbar behavior across desktop and mobile browsers.

## Features

- **Zero Dependencies:** Built with pure Vanilla JavaScript.
- **Touch & Mouse Support:** Supports interactive drag gestures for touch and mouse input.
- **Configurable Snap Points:** Configure bottom sheet heights and snapping behavior.
- **Scrollbar Shift Management:** Helps prevent layout shifts when locking body scrolling.
- **TypeScript Support:** Includes TypeScript declarations for IDE autocomplete and type checking.
- **Flexible Integration:** Designed for integration into modern JavaScript projects and browser-based applications.
