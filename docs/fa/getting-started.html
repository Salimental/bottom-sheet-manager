شروع به کار و نصب (Getting Started) ​

کتابخانه BottomSheetManager یک ابزار سبک، مستقل و بدون هیچ‌گونه وابستگی خارجی (Zero Dependency) است که برای ساخت باتم‌شیت‌های قابل سفارشی‌سازی و مدیریت هوشمند رفتار اسکرول‌بار در مرورگرهای دسکتاپ و موبایل طراحی شده است.

روش‌های نصب (Installation) ​

شما می‌توانید به سه روش مختلف این کتابخانه را به پروژه خود اضافه کنید:

۱. نصب از طریق NPM (پیشنهادی برای پروژه‌های مدرن) ​

برای پروژه‌های مبتنی بر React، Vue، Next.js، Vite یا هر پکیج باندلر دیگر، کافی است دستور زیر را در ترمینال خود اجرا کنید:

bash
npm install bottom-sheet-manager

سپس کدهای مربوطه را به صورت ES Module وارد (Import) کنید:

javascript
import { BottomSheetManager, ScrollbarManager } from 'bottom-sheet-manager';
import 'bottom-sheet-manager/dist/bottom-sheet-manager.min.css';

۲. استفاده از CDN یا تگ Script (برای پروژه‌های Vanilla JS / HTML) ​

اگر پروژه شما بدون باندلر است یا می‌خواهید سریعاً آن را در یک فایل HTML ساده تست کنید، می‌توانید از CDN رسمی jsDelivr استفاده کنید:

html
<!-- اضافه کردن استایل‌های ضروری -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.css">

<!-- اضافه کردن اسکریپت اصلی -->
<script src="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.js"></script>

نکته: هنگام استفاده از تگ اسکریپت معمولی، کلاس‌های BottomSheetManager و ScrollbarManager به صورت خودکار روی شیء window قرار می‌گیرند. (همچنین می‌توانید به جای @1.0.0 از @latest استفاده کنید تا همیشه آخرین نسخه بارگذاری شود).

۳. استفاده از ماژول مرورگر (ES Module via CDN) ​

اگر از ساختار ES Module در مرورگر استفاده می‌کنید (<script type="module">):

html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.css">

<script type="module">
  import { BottomSheetManager, ScrollbarManager } from 'https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.esm.min.js';
  
  const bs = new BottomSheetManager();
</script>

راه‌اندازی سریع (Quick Start) ​

پس از بارگیری استایل‌ها و اسکریپت کتابخانه، می‌توانید تنها با چند سطر کد اولین باتم‌شیت خود را ایجاد کنید:

javascript
// ۱. ساخت یک نمونه از مدیریت‌کننده باتم‌شیت
const bs = new BottomSheetManager();

// ۲. باز کردن یک باتم‌شیت جدید
const sheetId = bs.open({
  title: 'سلام دنیا!',
  content: '<p>این اولین باتم‌شیت من با BottomSheetManager است.</p>',
  height: '300px'
});

پشتیبانی از تایپ‌اسکریپت (TypeScript) ​

این کتابخانه به همراه فایل‌های اعلامیه نوع (index.d.ts) عرضه می‌شود. بنابراین در محیط‌های توسعه مانند VS Code، قابلیت Autocomplete برای تمام گزینه‌ها و متدها فعال خواهد بود:

typescript
import { BottomSheetManager, BottomSheetOptions } from 'bottom-sheet-manager';

const bs = new BottomSheetManager();

const options: BottomSheetOptions = {
  title: 'تنظیمات حساب کاربری',
  content: '<div>محتوای تنظیمات</div>',
  contentDraggable: true,
  snapOnDrag: true
};

bs.open(options);
