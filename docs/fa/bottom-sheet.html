مستندات باتم‌شیت (BottomSheet API) ​

کلاس BottomSheetManager کنترل کامل ساخت، بروزرسانی، مدیریت رویدادها، ژست‌های حرکتی (Drag/Snap) و بستن برگه‌ها را بر عهده دارد.

ساخت نمونه اولیه (Initialization) ​

برای شروع، یک نمونه از کلاس BottomSheetManager ایجاد کنید. شما می‌توانید تنظیمات سراسری (Global Options) را هنگام نمونه‌سازی مشخص کنید:

javascript
import { BottomSheetManager } from 'bottom-sheet-manager';

const bs = new BottomSheetManager({
  baseZIndex: 1000,             // لایه پایه z-index برای صفحات overlay و sheet
  contentDraggable: true,       // امکان درگ از روی محتوا به صورت پیش‌فرض
  snapOnDrag: false,            // فعال‌سازی پیش‌فرض نقاط چسبندگی (Snap Points)
  startExpanded: false,         // باز شدن اولیه روی حالت حداکثر ارتفاع
  mouseDrag: false,             // غیرفعال بودن درگ با ماوس در دسکتاپ به صورت پیش‌فرض
  touchDrag: true,              // فعال بودن درگ لمسی در موبایل به صورت پیش‌فرض
  ignoreMouseSelector: '',      // سلکتورهای نادیده‌گرفته‌شده برای ماوس
  ignoreTouchSelector: ''       // سلکتورهای نادیده‌گرفته‌شده برای لمس
});

متد open({ ... }) ​

با فراخوانی متد open می‌توانید یک باتم‌شیت جدید بسازید. این متد شناسه یکتای برگه (sheetId) را برمی‌گرداند.

نام پارامترنوعمقدار پیش‌فرضتوضیحات
titleرشته (String)""عنوان هدر باتم‌شیت
contentرشته یا DOM Node یا jQuery""محتوای داخلی باتم‌شیت (کد HTML، المنت اچ‌تی‌ام‌ال یا شیء jQuery)
heightرشتهnullارتفاع اولیه برگه (مثلاً '300px' یا '50vh'). در صورت خالی بودن، برگه به‌صورت auto-height عمل می‌کند.
widthرشتهnullعرض سفارشی برگه
classNameرشته""کلاس سفارشی CSS برای استایل‌دهی به برگه
snapOnDragبولینnullفعال‌سازی نقاط چسبندگی (Snap Points). نکته: برای فعال شدن این قابلیت، حتماً باید مقدار height مشخص شده باشد.
startExpandedبولینnullباز شدن اولیه روی حالت حداکثر ارتفاع (Max Snap Point) - نیازمند snapOnDrag فعال و داشتن height است.
contentDraggableبولینnullامکان کشیدن (Drag) برگه از طریق لمس محتوای داخلی
mouseDragبولینnullامکان درگ کردن با کلیک و درگ ماوس در دسکتاپ
touchDragبولینnullامکان درگ کردن با رویدادهای لمسی (Touch)
ignoreMouseSelectorرشتهnullسلکتور CSS المان‌هایی که نباید درگ ماوس روی آن‌ها عمل کند
ignoreTouchSelectorرشتهnullسلکتور CSS المان‌هایی که نباید درگ لمسی روی آن‌ها عمل کند
onOpenتابع (Callback)nullفراخوانی تابع پس از باز شدن کامل باتم‌شیت (ارسال شیء { id, sheet, content, overlay })
onCloseتابع (Callback)nullفراخوانی تابع هنگام بسته شدن باتم‌شیت

⚠️ نکته مهم درباره Snap Points (snapOnDrag): قابلیت Snap Points تنها زمانی کار می‌کند که یک ارتفاع اولیه صریح (height) برای برگه تعریف شده باشد. در حالت ارتفاع خودکار (auto-height)، قابلیت snapOnDrag عمل نخواهد کرد.

مثال کامل: ​

javascript
const sheetId = bs.open({
  title: 'جزئیات محصول',
  content: '<div class="product-info">محتوای طولانی یا فرم داخل باتم‌شیت...</div>',
  height: '400px', // تعیین ارتفاع برای فعال شدن snapOnDrag
  snapOnDrag: true,
  startExpanded: false,
  onOpen: ({ id, sheet, content, overlay }) => {
    console.log('باتم‌شیت باز شد. شناسه:', id);
  },
  onClose: () => {
    console.log('باتم‌شیت بسته شد!');
  }
});

متد ویرایش زنده: updateOptions(id, options) ​

با این متد می‌توانید در زمان اجرا (Runtime)، تنظیمات، عنوان، ابعاد یا گزینه‌های درگ یک باتم‌شیتِ باز را بدون نیاز به بستن و باز کردن مجدد تغییر دهید:

javascript
bs.updateOptions(sheetId, {
  title: 'عنوان به‌روزرسانی‌شده',
  height: '500px', // تغییر ارتفاع مجدداً اسنپ‌پوینت‌ها را بازنشانی می‌کند
  snapOnDrag: true,
  contentDraggable: false
});

بستن باتم‌شیت: close(id, options) ​

برای بستن برگه می‌توانید از متد close استفاده کنید:

javascript
// بستن برگه بر اساس شناسه اختصاصی
bs.close(sheetId);

// بستن آخرین باتم‌شیت فعال در بالای استک (Stack)
bs.close();

// بستن اجباری بدون بررسی حالت‌های اسنپ (عدم انقباض به ارتفاع پیش‌فرض قبل از بستن)
bs.close(sheetId, { force: true });

مدیریت تاریخچه مرورگر (History API) ​

کتابخانه به‌طور خودکار هنگام باز شدن هر برگه، یک State جدید به تاریخچه مرورگر اضافه می‌کند (pushState). با فشردن دکمه Back مرورگر یا دکمه بازگشت در موبایل، بالاترین باتم‌شیت فعال به‌طور خودکار بسته خواهد شد.
