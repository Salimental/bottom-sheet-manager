مدیریت اسکرول‌بار (ScrollbarManager) ​

کلاس ScrollbarManager یک ابزار مستقل و هوشمند برای مدیریت رفتار اسکرول بدنه سایت (document.body) هنگام باز شدن مودال‌ها، پاپ‌آپ‌ها و باتم‌شیت‌ها است.

نحوه حل مشکل Layout Shift ​

هنگامی که یک مودال یا باتم‌شیت باز می‌شود، اسکرول صفحه اصلی قفل می‌شود (overflow: hidden). این موضوع در مرورگرها باعث حذف اسکرول‌بار عمودی و پرش ناگهانی عرض صفحه (Layout Shift) به سمت راست می‌شود.

ScrollbarManager با محاسبه دقیق عرض اسکرول‌بارِ مرورگر کاربر و ست کردن متغیرهای CSS و پدینگ مناسب، از پرش صفحه جلوگیری می‌کند.

متدهای اصلی API ​

۱. متد add(id) ​

یک قفل اسکرول جدید با یک شناسه (ID) مشخص ثبت می‌کند. اگر اولین قفلی باشد که اضافه می‌شود، اسکرول بدنه قفل شده و پدینگ هوشمند اعمال می‌شود.

javascript
import { ScrollbarManager } from 'bottom-sheet-manager';

const scrollbar = new ScrollbarManager();

// قفل کردن اسکرول برای یک مودال سفارشی
scrollbar.add('my-custom-modal');

۲. متد remove(id) ​

قفل اسکرول مربوط به شناسه مشخص‌شده را حذف می‌کند. اگر تمام قفل‌ها برداشته شوند، اسکرول بدنه سایت به حالت اولیه بازمی‌گردد.

javascript
// برداشتن قفل و بازگرداندن اسکرول بدنه
scrollbar.remove('my-custom-modal');

۳. متد toggle(id) ​

وضعیت قفل اسکرول را برای یک شناسه مشخص تغییر می‌دهد (اگر قفل نباشد اضافه می‌کند و اگر قفل باشد آن را برمی‌دارد).

javascript
scrollbar.toggle('my-custom-modal');

متغیرهای CSS و استایل‌دهی ​

هنگام قفل شدن اسکرول، کلاس .full-width به تگ body اضافه می‌شود و متغیرهای زیر روی ریشه سند (:root) ست می‌شوند:

  • --scroll-bar-padding: مقدار عرض اسکرول‌بار محاسبه‌شده (مثلاً 17px).

مثال استفاده در CSS برای المنت‌های Fixed یا Sticky: ​

اگر المنت‌هایی با موقعیت ثابت (position: fixed) مانند هدر یا دکمه‌های شناور در صفحه دارید، می‌توانید با CSS زیر جلوی پرش آن‌ها را هنگام باز شدن مودال بگیرید:

css
/* جلوگیری از پرش هدرهای چسبان و ثابت */
body.full-width .fixed-header {
  padding-right: var(--scroll-bar-padding);
}
