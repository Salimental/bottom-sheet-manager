ScrollbarManager Documentation ​

The ScrollbarManager class is an independent and intelligent utility designed to manage the scrolling behavior of the document body (document.body) when modals, popups, or bottom sheets are open.

How It Solves Layout Shift ​

When a modal or bottom sheet opens, scrolling on the main page is typically locked (overflow: hidden). In many desktop browsers, hiding the vertical scrollbar causes the page content to abruptly shift to the right (Layout Shift).

ScrollbarManager solves this by calculating the exact width of the user's browser scrollbar and injecting appropriate CSS custom properties (variables) and padding, smoothly preventing layout jumps.

Core API Methods ​

1. add(id) ​

Registers a scroll lock for a specific identifier (id). If this is the first active lock, body scrolling is disabled and intelligent padding compensation is applied.

import { ScrollbarManager } from 'bottom-sheet-manager';

const scrollbar = new ScrollbarManager();

// Lock body scrolling for a custom modal
scrollbar.add('my-custom-modal');

2. remove(id) ​

Removes the scroll lock for the specified id. Once all registered locks are removed, body scrolling and layout padding are automatically restored to their original state.

// Unlock body scrolling
scrollbar.remove('my-custom-modal');

3. toggle(id) ​

Toggles the scroll lock state for a given id (adds the lock if absent, or removes it if present).

scrollbar.toggle('my-custom-modal');

CSS Variables & Styling ​

When body scrolling is locked, the .full-width class is added to the <body> element, and the following CSS custom property is injected onto the root (:root):

  • --scroll-bar-padding: The dynamically calculated width of the browser's scrollbar (e.g., 17px).

Example CSS Usage for Fixed or Sticky Elements ​

If your page contains fixed (position: fixed) or sticky elements (such as headers or floating action buttons), you can prevent them from shifting by using the injected CSS variable:

/* Prevent fixed/sticky header layout shift when scroll is locked */
body.full-width .fixed-header {
  padding-right: var(--scroll-bar-padding);
}
