Getting Started & Installation ​

BottomSheetManager is a lightweight, zero-dependency JavaScript library designed to create customizable bottom sheets and intelligently manage browser scrollbar behavior across desktop and mobile devices.

Installation Methods ​

You can add this library to your project in three different ways:

1. NPM Installation (Recommended for modern projects) ​

For projects using React, Vue, Next.js, Vite, or any module bundler, run the following command in your terminal:

bash
npm install bottom-sheet-manager

Then, import the required module and CSS stylesheet into your code:

javascript
import { BottomSheetManager, ScrollbarManager } from 'bottom-sheet-manager';
import 'bottom-sheet-manager/dist/bottom-sheet-manager.min.css';

2. CDN or Direct Script Tag (For Vanilla JS / HTML projects) ​

If your project does not use a bundler or you want to quickly test it inside a simple HTML page, you can use the official jsDelivr CDN:

html
<!-- Include required CSS styles -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.css">

<!-- Include main JavaScript file -->
<script src="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.js"></script>

Note: When loaded via a standard <script> tag, BottomSheetManager and ScrollbarManager classes are automatically attached to the global window object. (You can also replace @1.0.0 with @latest to always fetch the newest release).

3. ES Module in Browser (ESM via CDN) ​

If you are using native ES Modules directly in the browser (<script type="module">):

html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.min.css">

<script type="module">
  import { BottomSheetManager, ScrollbarManager } from 'https://cdn.jsdelivr.net/npm/bottom-sheet-manager@1.0.0/dist/bottom-sheet-manager.esm.min.js';
  
  const bs = new BottomSheetManager();
</script>

Quick Start ​

After importing the library styles and script, you can create your first bottom sheet with just a few lines of code:

javascript
// 1. Create an instance of BottomSheetManager
const bs = new BottomSheetManager();

// 2. Open a new bottom sheet
const sheetId = bs.open({
  title: 'Hello World!',
  content: '<p>This is my first bottom sheet with BottomSheetManager.</p>',
  height: '300px'
});

TypeScript Support ​

The package includes full TypeScript declaration files (index.d.ts). IDEs like VS Code will automatically provide autocompletion and type checking for all options and methods:

typescript
import { BottomSheetManager, BottomSheetOptions } from 'bottom-sheet-manager';

const bs = new BottomSheetManager();

const options: BottomSheetOptions = {
  title: 'Account Settings',
  content: '<div>Settings Content</div>',
  contentDraggable: true,
  snapOnDrag: true
};

bs.open(options);
