BottomSheet Manager API Documentation ​

The BottomSheetManager class provides full control over creating, updating, managing events, handling drag/snap gestures, and closing bottom sheets.

Initialization ​

To get started, instantiate the BottomSheetManager class. You can specify global default options during initialization:

javascript
import { BottomSheetManager } from 'bottom-sheet-manager';

const bs = new BottomSheetManager({
  baseZIndex: 1000,             // Base z-index for overlay and sheet elements
  contentDraggable: true,       // Allow dragging by touch/mouse on the content area by default
  snapOnDrag: false,            // Enable snap points on drag by default
  startExpanded: false,         // Open sheet in max expanded state by default
  mouseDrag: false,             // Enable dragging via mouse on desktop (disabled by default)
  touchDrag: true,              // Enable touch drag gestures on mobile (enabled by default)
  ignoreMouseSelector: '',      // CSS selector to ignore mouse drag events
  ignoreTouchSelector: ''       // CSS selector to ignore touch drag events
});

open({ ... }) Method ​

Call the open method to create and display a new bottom sheet. This method returns a unique sheet identifier (sheetId).

ParameterTypeDefaultDescription
titleString""Title text displayed in the sheet header
contentString | DOM Node | jQuery""Sheet body content (HTML string, HTML element, or jQuery object)
heightStringnullInitial height of the sheet (e.g., '300px', '50vh'). When omitted/null, the sheet operates in auto-height mode.
widthStringnullCustom width for the sheet
classNameString""Custom CSS class(es) to append to the sheet element
snapOnDragBooleannullEnables snap points during drag. Note: Requires an explicit height to be set.
startExpandedBooleannullOpens sheet directly at maximum snap height. Requires snapOnDrag and explicit height.
contentDraggableBooleannullAllows dragging the sheet by touching/swiping the content area
mouseDragBooleannullEnables mouse click-and-drag functionality on desktop
touchDragBooleannullEnables touch drag gestures
ignoreMouseSelectorStringnullCSS selector for elements that should ignore mouse dragging
ignoreTouchSelectorStringnullCSS selector for elements that should ignore touch dragging
onOpenFunctionnullCallback triggered after opening animation finishes. Receives { id, sheet, content, overlay }.
onCloseFunctionnullCallback triggered when the sheet starts closing

⚠️ Important Note on Snap Points (snapOnDrag): Snap Points functionality is only activated if an explicit initial height is specified. In auto-height mode, snapOnDrag will be disabled automatically.

Complete Example: ​

javascript
const sheetId = bs.open({
  title: 'Product Details',
  content: '<div class="product-info">Sheet content or form goes here...</div>',
  height: '400px', // Required for snapOnDrag to work
  snapOnDrag: true,
  startExpanded: false,
  onOpen: ({ id, sheet, content, overlay }) => {
    console.log('Bottom sheet opened. ID:', id);
  },
  onClose: () => {
    console.log('Bottom sheet closed!');
  }
});

Live Update: updateOptions(id, options) ​

Update properties, title, height, or drag options of an active bottom sheet at runtime without closing it:

javascript
bs.updateOptions(sheetId, {
  title: 'Updated Title',
  height: '500px', // Changing height recalculates snap points
  snapOnDrag: true,
  contentDraggable: false
});

Closing a Sheet: close(id, options) ​

Use the close method to dismiss sheets programmatically:

javascript
// Close a specific sheet by ID
bs.close(sheetId);

// Close the top-most active sheet in the stack
bs.close();

// Force close immediately (bypasses collapsing to default snap point)
bs.close(sheetId, { force: true });

Browser History Integration (History API) ​

The library automatically manages the browser's history state (pushState) whenever a sheet is opened. Pressing the browser's Back button or swipe-back gesture on mobile device will dismiss the top active bottom sheet automatically.
